# Prototype build and assembly guide

This guide builds three evaluation units after their critical purchase holds are closed. Use P1 for electrical debugging before duplicating wiring. No live hive or heavy load is used during bring-up.

1. **Incoming inspection.** Record MPN, board revision, serial/lot, invoices and battery polarity. Check load-cell label says150kg and obtain the matching metric drawing. Confirm mic actually ICS-43434; quarantine substitutions. Compare CARR-A and ordinary NOTE-MBGLN labels. Save supplier datasheets locally with date/hash in the project record.
2. **Mechanical dry fit.** Make a cardboard/printed envelope layout with exact carrier, battery and connectors. Resolve tray height and hive dimensions before molding. Assemble metal load-spreader subframes and pads first; fiberglass does not replace the structural fixture. Add adjustable stops/anti-lift only from reviewed drawing. Torque per cell supplier, mark witnesses, document moving dead weight.
3. **Power carrier.** Assemble U1–U4, isolation buffers, latch, supervisor and decoupling on reviewed soldered adapter/PCB. Inspect every pin under magnification; no solderless breadboard carries modem current. Test switch defaults using a current-limited bench supply with all expensive modules removed.
4. **Power rails.** HOST_FORCE_ON selected. Check battery distribution polarity, fuse, reverse protection, HOST_VSYS, HOST3V3 and AON3V3. Verify U2/U3/U4 low during reset. Check5V boost output unloaded and with a bridge-equivalent resistor, then connect HX711 VCC separately from3.3V VDD. Record E+ voltage. Battery disconnected during USB work.
5. **Signal wiring.** Follow WIRING.md row by row and label both ends. Install mux0x70; test each channel alone, not a global scan with every channel enabled. Reset mux between branches. Confirm SHT31 channels0/1, pressure2, accel3, light4. Add microphone last after HX PIO test passes.
6. **Firmware.** Fit SERVICE jumper GP22→GND. Flash pinned RPI_PICO UF2 via BOOTSEL. Copy every firmware `.py` file to device root. Generate config with tools/commission.py; review then copy as `config.json`. Save config and UF2 hash in service record. With service jumper installed, verify the REPL message and rails off. Remove jumper and reset to start.
7. **Offline smoke test.** Keep `cloud_enabled=false`, `host_poweroff=false`. A committed record must contain real sensor values or explicit null/fault for disconnected devices. Uncalibrated kg must be null. Copy journal via USB and run export_logs.py. Do not accept a sample solely because the console printed “CYCLE.”
8. **Calibration.** Follow CALIBRATION.md using traceable inert masses. Install fitted config in service mode. Temperature/humidity checks, ADC scaling, tilt reference and microphone orientation must also pass.
9. **Power-off test.** Disconnect USB. Inspect isolation by measuring HOST3V3 when switched off and AON current with all lines connected. Set `host_poweroff=true`, then move host selector to ATTN. Verify power-off/restart with no Notehub connection. Do20sleep/wake cycles,10cold battery starts and500accelerated bench cycles before extended field testing. If host stays off, select FORCE_ON to recover; do not reset/power-cycle Notecard repeatedly as a normal remedy.
10. **Optional cloud.** Bind NotecardUID to physical device in owned Notehub project. Configure route/test endpoint and permissions first. Set product/cloud_enabled in local config. Confirm a unique test record reaches durable server storage and duplicates do not create extra rows. Turnoff test and confirm hub.get returns off. Perform actual site coverage test before fitting all3.
11. **Enclosure.** Install breathable pressure vent, shaded ambient shield, protected brood cage, acoustic port membrane and light window. Conformal-coat only permitted PCB areas after masking every sensor port, connectors and antenna. Use drip loops and glands matched to cable diameter; strain-relieve without tying moving to fixed scale members. Keep battery out of structural load and direct sunlight. Close enclosure and repeat RF/weight checks.
12. **Release labels.** QR contains device lookup identifier only; no keys. Mark gross working limit, firmware, hardware revision, calibration ID and service date. Attach completed test record. P3 is deployed only after required gates pass.

## Tools and materials

Temperature-controlled iron, microscope, ESD setup, multimeter, current-limited supply able to test modem peaks, oscilloscope/current logger, logic analyzer, torque tools, reference masses, level/inclinometer, feeler gauges/dial indicators and calibrated climate reference. Rent/borrow if unavailable; ordinary multimeter averaging cannot capture2A bursts or sub-ms brownouts.

## Installed sensor placement

Brood probe mounts in a narrow protected cage adjacent to brood frames with beekeeper-approved clearance, not immersed in wax/honey or pressed against bees. Record frame/height/orientation and relocation date. Ambient probe sits shaded in ventilated radiation protection away from hive exhaust and electronics heat. Pressure vent faces down/protected from wind blast. Microphone port faces hive acoustic space behind a replaceable breathable membrane. Accelerometer screws rigidly to the moving hive tray. Light sensor receives ambient light through a characterized clean window; under-hive mounting measures shade, not open-sky irradiance. Reed sensor checks the specific lid/cover the user intends to detect.
